## Status model

| Status | Meaning |
|---|---|
| Proposed | Present in the source but not yet approved, owned, or scheduled |
| Accepted | Approved as an active delivery obligation |
| In progress | Implementation is active under a named owner and milestone |
| Verified | Acceptance criteria passed and evidence is linked |
| Deferred | Explicitly moved out of the current delivery scope without deletion |
| Superseded | Replaced by an approved ADR/RFC and updated source requirement |

## Traceability rule

Every epic, issue, pull request, test plan, release artifact, and Gauntlet evidence package must reference at least one requirement ID. Child requirements may add specificity but may not weaken the parent requirement without an approved change to the source of truth.
