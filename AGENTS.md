## Engineering rules

Use owned stable interfaces. Mature external dependencies may back them while proprietary replacements are constructed and tested. Do not promote an unaudited replacement to production by assertion, and do not stop building it because promotion is gated.

Use stable semantic IDs, versioned human-readable formats, deterministic serialization where required, explicit C++/Rust ABI/FFI, capability-based authorization, branch-scoped agent mutations, reproducible builds, signed artifacts, SBOM/provenance, and forward-compatible migrations. No public API, format, protocol object, chain state, ledger rule, wallet action, Arena result, or hardware profile changes silently.

Economic value uses integer minor or atomic units, separated ledgers/instruments, immutable balanced journals, holds, idempotency, compensating reversals, exact fee/royalty/tax/reserve separation, final-result settlement, and reconciliation. Sensitive identity and large media do not belong on-chain. A digital object does not grant copyright without an explicit license.
